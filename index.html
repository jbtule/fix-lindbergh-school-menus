Disclaimer

This is an unofficial, parent-made site - not built, run, or endorsed by Lindbergh School District.

It works by calling the public menu API of schoolnutritionandfitness.com directly - the third-party platform the district's own menu site runs on - just reformatted to be easier to use day-to-day.

That API isn't a published, supported integration, so it could change or be shut off at any time without notice, which would break this site.

Provided purely for convenience. Use at your own risk, and double-check anything that actually matters - especially allergy or dietary information - against the official source.
